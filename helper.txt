To implement this correctly, we need to distinguish between the **Internal Agent Logic** (what the agents do) and the **External Trace Logic** (how we log the overall run).

### 1. The Two Schemas: Who uses what?

* **`ContractKeyTermsExtraction` (The Artifact):** This is the **output** of the Extractor Agent. It is the core "business value" of the run. It goes inside the `artifacts` field of the larger result.
* **`AgentRunResult` (The Trace):** This is the **wrapper** managed by LangGraph. It tracks the metadata, the history of stages (Extractor, Auditor, etc.), and the final status. This is what you send to **Google Sheets**.

**Key Difference:** `ContractKeyTermsExtraction` is *what* we found; `AgentRunResult` is *how* we found it.

### 2. The API Endpoints

To make this functional and secure, you need these four endpoints:

| Endpoint | Method | Purpose |
| --- | --- | --- |
| `/auth/login` | `POST` | Exchanges username/password for a **JWT token**. |
| `/contract/process` | `POST` | Accepts a contract (Text/File). Triggers the LangGraph workflow. Returns `AgentRunResult`. |
| `/contract/status/{trace_id}` | `GET` | Fetches the current state of a run from SQLite (for long-running tasks). |
| `/analytics/dashboard` | `GET` | (Bonus) Redirects to your Google Sheet or returns a summary of total runs/confidence scores. |

### 5. Using DeepEval for the "Auditor"

In your Auditor node, initialize a metric:

```python
from deepeval.metrics import FaithfulnessMetric
from deepeval.test_case import LLMTestCase

def audit_node(state: AgentState):
    # 1. Setup the test case
    test_case = LLMTestCase(
        input=state["input_text"],
        actual_output=str(state["artifacts"]),
        retrieval_context=[state["input_text"]]
    )
    # 2. Measure
    metric = FaithfulnessMetric(threshold=0.8)
    metric.measure(test_case)
    
    # 3. Update State for the AgentRunResult schema
    state["confidence"] = metric.score
    state["confidence_rationale"] = metric.reason
    return state

```
